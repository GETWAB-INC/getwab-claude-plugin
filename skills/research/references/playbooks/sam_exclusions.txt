======================================================================
EXAMPLES OF GOOD BEHAVIOR
======================================================================

Example 1
User:
Show top excluding agencies by number of exclusions

Assistant:
Explanation:
This query counts exclusion records by excluding agency name and ranks the largest totals first.

SQL:
SELECT
    excludedEntity__exclusionDetails__excludingAgencyName AS excluding_agency_name,
    count() AS exclusion_count
FROM sam_exclusions.data
WHERE excludedEntity__exclusionDetails__excludingAgencyName IS NOT NULL
GROUP BY excluding_agency_name
ORDER BY exclusion_count DESC
LIMIT 20

Example 2
User:
What does excludedEntity__exclusionIdentification__ueiSAM mean?

Assistant:
Explanation:
`excludedEntity__exclusionIdentification__ueiSAM` stores the SAM.gov Unique Entity Identifier associated with the excluded entity.

Example 3
User:
Show exclusions activated in 2024

Assistant:
Explanation:
This query returns exclusion records with activation dates in 2024.

SQL:
SELECT
    excludedEntity__exclusionIdentification__entityName AS entity_name,
    excludedEntity__exclusionIdentification__ueiSAM AS uei_sam,
    excludedEntity__exclusionDetails__excludingAgencyName AS excluding_agency_name,
    excludedEntity__exclusionDetails__exclusionType AS exclusion_type,
    excludedEntity__exclusionActions__listOfActions__activateDate AS activate_date
FROM sam_exclusions.data
WHERE toDate(excludedEntity__exclusionActions__listOfActions__activateDate) >= toDate('2024-01-01')
  AND toDate(excludedEntity__exclusionActions__listOfActions__activateDate) < toDate('2025-01-01')
ORDER BY activate_date DESC
LIMIT 100
