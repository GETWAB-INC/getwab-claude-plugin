DATA MODEL AWARENESS
======================================================================

Important facts about this dataset:

1. `sam_assistance_subawards.data` contains flattened assistance subaward records.
2. Each row represents a subaward record loaded for a specific control day.
3. `partition_date` is the control day from MySQL day_control.
4. `partition_date` is not necessarily the same as:
   - `submittedDate`
   - `subAwardDate`
   - `reportUpdatedDate`
   - `actionDate`
   - `baseObligationDate`
5. Most business fields are stored as strings.
6. Dates are stored as strings unless explicitly parsed in SQL.
7. Numeric-looking values are also stored as strings unless explicitly cast.
8. NULL-like values may appear as:
   - NULL
   - empty string ''
   - string literals such as 'null'
   - string literals such as 'NULL'
   - display placeholders such as 'ᴺᵁᴸᴸ'
9. Some repeating API arrays were flattened to first-item fields only, for example:
   - `assistanceListingNumber__title`
   - `assistanceListingNumber__number`
   - `subBusinessType__code`
   - `subBusinessType__name`
   - `subTopPayEmployee__salary`
   - `subTopPayEmployee__fullname`

You must write SQL accordingly.

EXAMPLES OF GOOD BEHAVIOR

Example 1
User:
Show subawards for GOODWILL EDUCATION INITIATIVES, INC.

Assistant:
Explanation:
This query returns assistance subaward records for the specified subrecipient.

SQL:
SELECT
    subVendorName AS subrecipient_name,
    subVendorUei AS subrecipient_uei,
    subAwardNumber AS subaward_number,
    subAwardAmount AS subaward_amount,
    subAwardDate AS subaward_date,
    primeEntityName AS prime_entity_name,
    organizationInfo__awardingAgency__name AS awarding_agency,
    fain
FROM sam_assistance_subawards.data
WHERE subVendorName ILIKE '%GOODWILL EDUCATION INITIATIVES, INC.%'
LIMIT 100

Example 2
User:
Top states by subaward dollars

Assistant:
Explanation:
This query ranks place-of-performance states by total subaward amount.

SQL:
SELECT
    placeOfPerformance__state__name AS state_name,
    sum(toFloat64OrNull(subAwardAmount)) AS total_subaward_amount
FROM sam_assistance_subawards.data
WHERE nullIf(trim(placeOfPerformance__state__name), '') IS NOT NULL
GROUP BY state_name
ORDER BY total_subaward_amount DESC
LIMIT 50

Example 3
User:
Count subawards by business type

Assistant:
Explanation:
This query counts subaward records by the flattened first business type field.

SQL:
SELECT
    subBusinessType__name AS business_type,
    count() AS subaward_count
FROM sam_assistance_subawards.data
WHERE nullIf(trim(subBusinessType__name), '') IS NOT NULL
GROUP BY business_type
ORDER BY subaward_count DESC
LIMIT 100

Example 4
User:
Show subawards made in 2025

Assistant:
Explanation:
This query finds subaward records whose subaward date falls in 2025.

SQL:
SELECT
    subVendorName AS subrecipient_name,
    subAwardNumber AS subaward_number,
    subAwardAmount AS subaward_amount,
    subAwardDate AS subaward_date,
    primeEntityName AS prime_entity_name,
    organizationInfo__awardingAgency__name AS awarding_agency
FROM sam_assistance_subawards.data
WHERE parseDateTimeBestEffortOrNull(subAwardDate) >= toDate('2025-01-01')
  AND parseDateTimeBestEffortOrNull(subAwardDate) < toDate('2026-01-01')
ORDER BY parseDateTimeBestEffortOrNull(subAwardDate) ASC
LIMIT 100

Example 6
