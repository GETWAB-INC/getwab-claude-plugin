======================================================================
INTENT AND QUERY RULES
======================================================================

1. Current Opportunity lookup

Use current.noticeid for exact Notice ID lookup.
Use current.solicitation_number for solicitation lookup.
Use ILIKE on current.title for title/keyword lookup.

2. Open opportunities

Use:

is_active = 1
AND (
    response_deadline_at IS NULL
    OR response_deadline_at >= now()
)

Do not assume that a missing deadline means closed.

3. Closing soon

Use a half-open timestamp range:

response_deadline_at >= now()
AND response_deadline_at < now() + INTERVAL 30 DAY

4. Current buyer filtering

Use full_parent_path_name for hierarchy text search and
full_parent_path_code for exact hierarchy-code search.

5. NAICS

For one code, account for both normalized representations:

naics_code = '541512'
OR has(naics_codes, '541512')

6. PSC

Use classification_code.

7. Awards

Use award_number, award_amount_value, award_at, awardee_name, awardee_uei, and
awardee_cage_code. Do not parse award_json when normalized fields suffice.

8. Contacts

Join current_contacts only when contact-level output or filtering is requested.
If counting opportunities after a one-to-many join, use uniqExact(current.noticeid)
instead of count().

9. Resources

Join current_resources only when attachment/resource-level output or filtering
is requested. If counting opportunities after the join, use
uniqExact(current.noticeid).

10. Archive research

Filter archive early by typed dates, exact solicitation, Notice ID, NAICS, PSC,
agency, office, or fiscal-year partition. Broad archive scans must aggregate or
use a reasonable LIMIT.

11. Historical versions and duplicates

archive contains distinct historical Notice IDs and may contain multiple rows
associated with the same solicitation. Count records with count(); count unique
notices with uniqExact(noticeid); count unique solicitations with
uniqExactIf(sol, trim(sol) != '').

12. Missing values

Current normalized strings use an empty string for missing values. Use:

trim(column) != ''

Nullable dates and amounts use IS NOT NULL.

Archive source strings may contain legacy placeholders. Prefer typed helpers;
otherwise normalize '', 'null', 'NULL', and 'ᴺᵁᴸᴸ'.

EXAMPLES

Example 1: Current Notice ID lookup

Explanation:
This query returns the canonical current SAM.gov record for the Notice ID.

SQL:
SELECT
    noticeid,
    title,
    solicitation_number,
    notice_type,
    full_parent_path_name,
    posted_at,
    response_deadline_at,
    naics_code,
    classification_code,
    ui_link
FROM sam_opportunities.current
WHERE noticeid = '01834b1c87334dadb7d106b968c78a8e'
LIMIT 1

Example 2: Open opportunities for NAICS

Explanation:
This query returns open current opportunities associated with NAICS 541512.

SQL:
SELECT
    noticeid,
    title,
    solicitation_number,
    notice_type,
    full_parent_path_name,
    posted_at,
    response_deadline_at,
    set_aside_description,
    ui_link
FROM sam_opportunities.current
WHERE is_active = 1
  AND (
      naics_code = '541512'
      OR has(naics_codes, '541512')
  )
  AND (
      response_deadline_at IS NULL
      OR response_deadline_at >= now()
  )
ORDER BY posted_at DESC
LIMIT 100

Example 3: Current Opportunity contacts

Explanation:
This query returns normalized contacts for the requested current Opportunity.

SQL:
SELECT
    c.noticeid,
    c.title AS opportunity_title,
    ct.type AS contact_type,
    ct.title AS contact_title,
    ct.full_name,
    ct.email,
    ct.phone,
    ct.fax
FROM sam_opportunities.current AS c
INNER JOIN sam_opportunities.current_contacts AS ct
    ON ct.noticeid = c.noticeid
WHERE c.noticeid = '01834b1c87334dadb7d106b968c78a8e'
ORDER BY ct.type, ct.full_name

Example 4: Opportunity resources

Explanation:
This query returns the attachment and resource URLs for the current Opportunity.

SQL:
SELECT
    c.noticeid,
    c.title,
    r.resource_url
FROM sam_opportunities.current AS c
INNER JOIN sam_opportunities.current_resources AS r
    ON r.noticeid = c.noticeid
WHERE c.noticeid = '01834b1c87334dadb7d106b968c78a8e'
ORDER BY r.resource_url

Example 5: Closing in the next 30 days

Explanation:
This query returns current active opportunities with a response deadline in the
next 30 days.

SQL:
SELECT
    noticeid,
    title,
    solicitation_number,
    full_parent_path_name,
    response_deadline_at,
    naics_code,
    classification_code,
    ui_link
FROM sam_opportunities.current
WHERE is_active = 1
  AND response_deadline_at >= now()
  AND response_deadline_at < now() + INTERVAL 30 DAY
ORDER BY response_deadline_at ASC
LIMIT 100

Example 6: Buyer ranking without contact duplication

Explanation:
This query ranks current buying hierarchies by unique Opportunity count.

SQL:
SELECT
    full_parent_path_name AS buying_hierarchy,
    uniqExact(noticeid) AS opportunity_count
FROM sam_opportunities.current
WHERE trim(full_parent_path_name) != ''
GROUP BY buying_hierarchy
ORDER BY opportunity_count DESC
LIMIT 50

Example 7: Historical solicitation lookup

Explanation:
This query searches the historical archive for all records carrying the exact
solicitation number.

SQL:
SELECT
    noticeid,
    title,
    sol AS solicitation_number,
    department_ind_agency,
    sub_tier,
    office,
    posted_at,
    response_deadline_at,
    type AS notice_type,
    naicscode AS naics_code,
    classificationcode AS psc_code,
    awardnumber AS award_number,
    award_amount_value,
    awardee,
    link
FROM sam_opportunities.archive
WHERE sol = '36C26126R0052'
ORDER BY posted_at DESC
LIMIT 100

Example 8: Historical trend by fiscal year

Explanation:
This query counts archived Notice IDs by source fiscal year without scanning
current API records.

SQL:
SELECT
    source_fiscal_year,
    uniqExact(noticeid) AS archived_notice_count
FROM sam_opportunities.archive
WHERE source_fiscal_year IS NOT NULL
GROUP BY source_fiscal_year
ORDER BY source_fiscal_year

Example 9: Historical awardees by parsed amount

Explanation:
This query ranks historical awardee strings using the normalized numeric award
amount.

SQL:
SELECT
    awardee,
    sum(award_amount_value) AS total_award_amount,
    uniqExact(noticeid) AS notice_count
FROM sam_opportunities.archive
WHERE trim(awardee) != ''
  AND award_amount_value IS NOT NULL
GROUP BY awardee
ORDER BY total_award_amount DESC
LIMIT 50

Example 10: Exact solicitation-family records

Explanation:
This query finds historical records sharing the current Opportunity's exact
non-empty solicitation number. These are members of one solicitation family,
not automatically predecessors or incumbents.

SQL:
WITH target AS
(
    SELECT
        solicitation_number
    FROM sam_opportunities.current
    WHERE noticeid = '01834b1c87334dadb7d106b968c78a8e'
    LIMIT 1
)
SELECT
    a.noticeid,
    a.title,
    a.sol AS solicitation_number,
    a.posted_at,
    a.department_ind_agency,
    a.office,
    a.naicscode AS naics_code,
    a.classificationcode AS psc_code,
    a.awardnumber,
    a.award_amount_value,
    a.awardee
FROM sam_opportunities.archive AS a
CROSS JOIN target AS t
WHERE trim(t.solicitation_number) != ''
  AND a.sol = t.solicitation_number
ORDER BY a.posted_at DESC
LIMIT 100
